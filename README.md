# SBK Chat — the Android application, for downloading

This repository holds **one thing**: the installer (APK) of the SBK Auto Trading chat application,
so that customers can download it quickly and reliably from anywhere.

**There is no source code here.** The application's code lives in the private repository
`SBK-Application`, and the chat it talks to in `SBK-Chat`.

## How people download it

They do not come here. They open the app's own page and press the button:

    https://chat-application.sbkautotrading.com

That address hands the download to the release below, so the file arrives whole even on a slow
connection — which is the reason this repository exists.
